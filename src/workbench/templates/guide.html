Everyday guide

Open your sessions, decide what matters, and keep your work up to date.

Start your day

Run these commands in a regular terminal shell, outside an agent conversation or launcher menu. These examples use an installed launcher with the AIW contexts configured.

Open all enabled agent tabs:

~/.local/bin/ai-workbench up

Open only your daily AIW conversation:

~/.local/bin/ai-workbench up aiw

Open AIW Dev:

~/.local/bin/ai-workbench up ai-workbench

Leave existing healthy sessions open. The launcher reuses them; if a tab is already attached, switch to it. Saved conversation bindings are preserved. Depending on the provider and configuration, a tab may offer a selection menu.

After a reboot, use up to reopen your tabs. Installed background collectors can start automatically at login; opening agent tabs is a separate step. Running up aiw opens only AIW.

Choose where to work

  • AIW: your daily conversation for priorities, tasks, waiting items, and accomplishments.
  • AIW Dev: changes to Workbench itself—bugs, features, tests, and releases.
  • The website: view the same work state on the dashboard, create a human task, and open reports. Bookmark your configured Workbench website.

Opening a session or seeing an activity signal does not itself authorize or complete work.

Ask what needs attention

Try: “What needs my attention?” or “What should I work on next?”

AIW can explain blockers, decisions, and monitoring problems. A suggestion is separate from work you have agreed to do.

Keep tasks current

  • “Track this: prepare the release notes.”
  • “I’m working on the release notes now.”
  • “The release notes are waiting for review.”
  • “The release notes are finished; record the result.”

Name the task clearly and give useful context or a result link. Explicit updates keep the record accurate: an agent running, going quiet, or finishing a response does not prove that a task is complete.

Review and wrap up

Ask “Prepare my daily standup,” “What did I accomplish today?” or “What is still waiting?”

You can also open Standup, Accomplishments, or Actions. Check the report’s displayed time window, then tell AIW about missing outcomes or changed priorities.

When something looks wrong

Ask: “Check Workbench health and this session before restarting anything.”

Check all configured sessions:

~/.local/bin/ai-workbench status

Check only AIW:

~/.local/bin/ai-workbench status aiw

Collectors report activity in the background. An offline collector means visibility is missing, not that your work failed. An open terminal is also not proof that its agent is healthy. Preserve working conversations and investigate the specific issue instead of restarting everything.

For scrolling, selection, or link behavior, ask AIW to inspect your terminal settings and preserve live sessions. You do not need to manage collectors or remember API commands for everyday use.
